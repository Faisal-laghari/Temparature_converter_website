# Temperature Converter Tool

A professional-grade, vanilla JavaScript temperature converter.

## Features
- **Precise Calculations**: Uses standard physical constants.
- **Input Validation**: Rejects non-numeric inputs immediately.
- **Physical Boundaries**: Prevents conversion of temperatures below Absolute Zero.
- **Simultaneous Output**: Displays conversions across all units (C, F, K) at once.
- **Responsive Design**: Mobile-friendly, clean UI.

## How to use
1. Open `index.html` in any modern web browser.
2. Enter a numeric value in the input field.
3. Select the source unit from the dropdown.
4. Click "Convert" to see the results.
